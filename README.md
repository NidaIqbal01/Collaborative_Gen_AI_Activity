# Matrix Transpose in C++

## Description
This program calculates the transpose of a matrix in C++. The transpose is obtained by converting the rows of the original matrix into columns and the columns into rows.

## How It Works
1. Takes the matrix dimensions and elements as input.
2. Calculates the transpose by swapping rows and columns.
3. Displays the original matrix and its transpose.

## Example
**Original Matrix:**
```text
1 2 3
4 5 6
```

**Transposed Matrix:**
```text
1 4
2 5
3 6
```

## Language
- C++
